# 常见食材搭配与替换

> 说明：本页由 OrangeDiary 项目整理，属于通用搭配经验，不是营养学结论；
> 具体用量与营养以菜谱和食物库计算为准。

## 蛋类
- 鸡蛋 + 番茄：番茄的酸味提鲜，先炒蛋再回锅，蛋不易老。
- 鸡蛋 + 韭菜：韭菜易出水，先炒蛋、后下韭菜，全程大火。
- 鸡蛋 + 木耳 + 黄瓜：可加瘦肉片，适合快炒。

## 肉类
- 五花肉 + 青椒：青椒先干煸，五花肉煸出油，不用另外多放油。
- 鸡肉 + 香菇：适合蒸或焖，香菇泡发的水可以代替部分清水提味。
- 牛肉 + 大葱：牛肉逆纹切薄片，大火短炒，葱最后下。
- 猪肉 + 土豆：适合炖煮，土豆吸汁后口感绵软。

## 素菜
- 豆腐 + 白菜：清淡炖煮，豆腐先用淡盐水泡过不易碎。
- 西兰花 + 蒜：焯水 1 分钟后快炒，能保持翠绿。
- 茄子 + 蒜 + 生抽：茄子先腌再蒸，能明显减少用油。
- 土豆 + 青椒：土豆丝洗掉淀粉再炒，脆而不粘。

## 常见调料替换
- 没有生抽：可用少量老抽加盐代替，但颜色会偏深。
- 没有蚝油：可用生抽加一点点糖代替，鲜味会弱一些。
- 没有料酒：可用少量黄酒或清水中加姜片代替，去腥效果下降。
- 没有冰糖：可用白砂糖代替，炒糖色时更容易焦，需要更小的火。
- 不吃辣：干辣椒、小米椒直接省略，花椒可以保留提香。

## 搭配原则
- 荤素搭配：一餐里同时有蛋白质来源和蔬菜。
- 味道互补：酸味食材（番茄、醋）适合搭配油腻的肉类。
- 口感对比：脆的食材（黄瓜、芹菜）配软的食材（豆腐、茄子）。
